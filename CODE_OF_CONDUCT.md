# Code Of Conduct

## Expected Conduct

ResAgent contributors and maintainers are expected to:

- discuss technical decisions directly and respectfully;
- review ideas and changes without attacking the person proposing them;
- provide enough evidence for claims about behavior, security, and test results;
- respect privacy and remove credentials, private host details, and sensitive output;
- accept reasonable maintainer direction on scope, architecture, and repository safety;
- give credit for upstream work and prior contributions.

## Unacceptable Conduct

The following behavior is not accepted in project spaces:

- harassment, threats, discrimination, or personal attacks;
- publishing another person's private information or credentials;
- deliberately misleading test, security, or provenance claims;
- spam, impersonation, or repeated disruption of technical discussion;
- unauthorized access to repository infrastructure, provider accounts, or remote systems;
- retaliation against a person who reports a security or conduct concern in good faith.

## Scope

This policy applies to issues, pull requests, reviews, repository discussions, release activity,
and other spaces where someone represents the ResAgent project.

## Reporting

For ordinary conduct concerns, contact a repository maintainer privately through an appropriate
GitHub channel. For vulnerabilities, credential exposure, or infrastructure abuse, follow
[SECURITY.md](SECURITY.md) and use the private Security Advisory form.

Maintainers may edit or remove content, limit participation, close contributions, or block
accounts when necessary to protect contributors and the project. Reports will be evaluated based
on available evidence and handled as privately as practical.
